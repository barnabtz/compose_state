📋Project Overview

Compose State is a comprehensive Flutter state management package inspired by Jetpack Compose, offering reactive state, centralized ViewModel scoping, API handling, and persistence for basic, complex, and dynamic objects.

🌟 Key Features

🔄 Reactive State Types

MutableState, PersistableState, ApiState, DerivedState, HistoryState, StreamState, and SignalState for every use case.

🛡️ Error Handling

Comprehensive error recovery strategies, retry mechanisms, and error boundaries with automatic fallbacks.

🧠 Memory Management

Automatic disposal, weak reference tracking, and memory leak detection for optimal performance.

⚡ Performance Optimization

Deep equality checking, notification batching, and optimized rebuilds for smooth user experiences.

🧪 Testing Infrastructure

Mock implementations, state change tracking, and comprehensive testing utilities.

🔒 Type Safety

Runtime type validation for serialization and persistence operations with compile-time safety.

Simple Counter App Simple

The classic counter example demonstrating basic reactive state management.

import 'package:flutter/material.dart'; import 'package:compose_state/compose_state.dart'; // Create a reactive state final counter = mutableStateOf(0); class CounterApp extends StatelessWidget { @override Widget build(BuildContext context) { return MaterialApp( home: Scaffold( appBar: AppBar( title: Text('Counter App'), backgroundColor: Colors.blue, ), body: Center( child: Column( mainAxisAlignment: MainAxisAlignment.center, children: [ Text( 'You have pushed the button this many times:', style: TextStyle(fontSize: 16), ), SizedBox(height: 20), StateBuilder<int>( state: counter, builder: (context, count) { return Text( '$count', style: Theme.of(context).textTheme.headlineMedium?.copyWith( color: Colors.blue, fontWeight: FontWeight.bold, ), ); }, ), ], ), ), floatingActionButton: Column( mainAxisAlignment: MainAxisAlignment.end, children: [ FloatingActionButton( onPressed: () => counter.value++, tooltip: 'Increment', child: Icon(Icons.add), ), SizedBox(height: 10), FloatingActionButton( onPressed: () => counter.value--, tooltip: 'Decrement', child: Icon(Icons.remove), ), ], ), ), ); } }
Key Concepts:
  • mutableStateOf() - Creates reactive state
  • StateBuilder - Rebuilds UI when state changes
  • Automatic disposal and memory management

Form Validation with Derived State Simple

A shopping cart implementation demonstrating complex state management with derived calculations.

} // Sample products final sampleProducts = [ Product(id: '1', name: 'Laptop', price: 999.99, image: '💻', description: 'High-performance laptop'), Product(id: '2', name: 'Phone', price: 699.99, image: '📱', description: 'Latest smartphone'), Product(id: '3', name: 'Headphones', price: 199.99, image: '🎧', description: 'Wireless headphones'), Product(id: '4', name: 'Watch', price: 299.99, image: '⌚', description: 'Smart watch'), ]; // Cart state final cartItems = mutableStateOf<List<CartItem>>([]); // Derived states for calculations final cartItemCount = derivedStateOf(() { return cartItems.value.fold<int>(0, (sum, item) => sum + item.quantity); }); final cartSubtotal = derivedStateOf(() { return cartItems.value.fold<double>(0, (sum, item) => sum + item.totalPrice); }); final cartTax = derivedStateOf(() { return cartSubtotal.value * 0.08; // 8% tax }); final cartTotal = derivedStateOf(() { return cartSubtotal.value + cartTax.value; }); final isCartEmpty = derivedStateOf(() { return cartItems.value.isEmpty; }); // Cart operations class CartService { static void addToCart(Product product) { final currentItems = List<CartItem>.from(cartItems.value); final existingIndex = currentItems.indexWhere((item) => item.product.id == product.id); if (existingIndex != -1) { // Update quantity if item exists currentItems[existingIndex] = currentItems[existingIndex].copyWith( quantity: currentItems[existingIndex].quantity + 1, ); } else { // Add new item currentItems.add(CartItem(product: product, quantity: 1)); } cartItems.value = currentItems; } static void removeFromCart(String productId) { cartItems.value = cartItems.value.where((item) => item.product.id != productId).toList();
